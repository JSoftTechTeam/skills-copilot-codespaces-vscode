# JSC Innovation City™ — Clickable Developer Demo

This branch contains the interactive reference demo for **JSC Innovation City™** and the **Data Harbor Golden Mission**.

## Demo flow

Learner → Data Harbor mission → VISTA scaffold/retry → mastery → credential → Instructor → Executive → Developer view.

## Architecture spine

Experience → Event → Evidence → Mastery → Adaptation → Credential → Opportunity

## Local run

Open `innovation-city-demo/index.html` in a modern browser.

## Production handoff

This demo is a front-end reference implementation. Agent developers should replace simulated services with VLME/xAPI event ingestion, the governed mastery engine, Azure AI/VISTA orchestration, persistence, Fabric analytics, and production credential services.
